Свободный переключатель раскладки клавиатуры для Windows (аналог Punto Switcher / xneur и др.).

**Платформа:** Windows 10/11, x64  
**Версия:** 0.992.2 beta  
**Автор:** Tap3ah  
**Лицензия:** GNU GPL v3+

Swaply живёт в системном лотке, следит за набором текста и исправляет слово,
если оно набрано в неправильной раскладке (QWERTY ↔ ЙЦУКЕН).

## Что нового в 0.992.2 beta

- Исправлен Linux/X11 порт: распознавание старых кириллических keysym (`0x06xx`, их отдаёт раскладка `ru`), разрыв событий XRecord, зависание после первой конверсии (контекст записи не выключался без flush)
- Конверсия выполняется одним атомарным залпом (~1 мс) и не вклинивается в быстрый набор: между стиранием слова и перепечаткой не может прилететь следующая клавиша
- После конверсии не теряется пробел/Enter: X-сервер подавлял «повторное» нажатие всё ещё зажатой клавиши, слова слипались
- Исправление гибридных слов: если раскладка щёлкнула в середине слова, после пробела поток клавиш перечитывается в целевой раскладке и слово исправляется целиком (`gj`+«дними» → «подними»)
- На Cinnamon раскладка переключается через саму оболочку (D-Bus, fire-and-forget), теперь её хранитель не откатывает группу обратно; на остальных DE — обычный XkbLockGroup
- В .deb явно добавлена зависимость от glib (gio); сборочный скрипт пакета работает и на FAT/exFAT-разделах

## Возможности

- Автопереключение EN ↔ RU по словарю после конца слова
- Эвристики невозможных сочетаний букв из xneur (`proto`)
- Словарь исключений: URL, IP, MAC, `.рф`, служебные слова; свои слова можно добавить
- Ручная конвертация текущего слова и выделенного текста
- Обучение: запомнить слово в словарь текущей раскладки
- Отмена последней конвертации (повторная отмена возвращает исправление)
- Горячие клавиши: клавиша из списка + Ctrl / Alt / Shift / Win
- Пропуск полей пароля и исключённых процессов
- Запуск вместе с Windows (не в портативной сборке)
- Проверка обновлений и автообновление
- Окно параметров на русском


По умолчанию:

| Действие | Клавиши |
|---|---|
| Конвертировать слово | Pause |
| Конвертировать выделение | Ctrl+Pause |
| Добавить в словарь | Alt+Pause |
| Отменить конвертацию | Shift+Pause |

Pause без набранного слова тоже конвертирует выделение.

## Установка

Готовые файлы: [релизы на GitHub](https://github.com/TAPZAH/swaply/releases).

- **Инсталлятор** `Swaply-0.986-beta-setup.exe` — в профиль пользователя, ярлык в меню Пуск и (по выбору) на рабочем столе
- **Портативная сборка** `Swaply-0.986-beta-portable.zip` — распаковать и запустить `Swaply.exe` (в архиве есть маркер `portable`)
если в папке есть маркер portable, настройки пишутся в эту папку, если его удалить то будут писаться в профиль пользователя
- **Исходники** `Swaply-0.986-beta-src.zip` или репозиторий на GitHub

Инсталлятор закрывает уже запущенную копию программы, чтобы заменить файлы.

## Обновления

Проверка обновлений идёт по HTTPS к официальным релизам репозитория на GitHub.
При выходе новой версии предлагается скачать и запустить установщик; после
подтверждения программа закрывается, а установщик ставит новую версию.
Автопроверка при запуске отключается в параметрах («Проверять обновления»).

## Портативный режим

Рядом с `Swaply.exe` должен лежать файл с именем `portable` (без расширения). Тогда `config.json` пишется в ту же папку, автозагрузка через реестр отключена.

## Linux (X11)

### Где работает

- **Только X11 (Xorg).** Нужны расширения `RECORD` (глобальный перехват клавиш) и `XTEST` (ввод) — в обычном Xorg они включены по умолчанию.
- **Обе раскладки должны быть в XKB-группах**, например `setxkbmap -layout us,ru`. Группы определяются по факту: ищется группа, где клавиша `a` даёт латинскую букву, и группа, где — кириллицу. Порядок `us,ru` или `ru,us` не важен.
- Рассчитано на обычные Xorg-сессии с системным лотком: **KDE Plasma (X11), XFCE, MATE, Cinnamon, LXQt**.
- **GNOME:** сам демон работает; но значок в трее (`GtkStatusIcon`) в GNOME по умолчанию не отображается — нужны расширения AppIndicator/StatusIcon, иначе запускайте демон напрямую без трея.
- **Переключение раскладки.** На Cinnamon и GNOME оболочка откатывает внешний `XkbLockGroup`, поэтому там переключение идёт через D-Bus (`org.Cinnamon` → `ActivateInputSourceIndex`). На остальных DE — стандартный `XkbLockGroup`.

### Ограничения

- **Wayland не поддерживается.** Глобальный перехват и синтетический ввод запрещены моделью безопасности Wayland. В Wayland-сессии (включая приложения через XWayland) переключение работать не будет.
- **Нет пропуска полей пароля** (в отличие от Windows). На Linux текст правится везде, в том числе в полях ввода пароля — набирайте пароль в нужной раскладке или временно отключайте Swaply.
- **Нет проверки и автообновления** (только Windows).
- **Хоткеи:** работают автопереключение и ручная конвертация текущего слова (`Pause`). Конвертация выделения, обучение слову и отмена последней конвертации на Linux не реализованы.
- **Нет ранней конвертации по первым буквам** (как на Windows): слово исправляется на разделителе — пробел, Enter или Tab.
- Клавиша-разделитель должна быть физически отпущена; приложение само логически отпускает её перед перепечаткой.
- На ноутбуках без клавиши `Pause` ручную конвертацию вызвать нечем (автопереключение по пробелу работает).
- Пакет `.deb` собран под `amd64`.

### Установка (Linux)

```
sudo apt install ./swaply_0.992.2_amd64.deb
swaply-tray
```

Трей запускает демон `swaply-x11` и останавливает его при выходе. Конфиг — `~/.config/swaply/config.json`, перечитывается на лету (смена настроек применяется без перезапуска). Демон можно запускать и отдельно: `swaply-x11`.

### Сборка (Linux)

```
sudo apt install build-essential cmake libx11-dev libxtst-dev libgtk-3-dev libglib2.0-dev pkg-config
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
sudo cmake --install build
```

Пакет `.deb`: `installer/linux/build_deb.sh`.

## Сборка (Windows)

```
cmake -S . -B build -A x64
cmake --build build --config Release
```

Инсталлятор (NSIS):

```
makensis installer\swaply.nsi
```
