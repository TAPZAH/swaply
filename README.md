Свободный переключатель раскладки клавиатуры для Windows (аналог Punto Switcher / xneur).

**Платформа:** Windows 10/11, x64  
**Версия:** 0.985 beta  
**Автор:** Tap3ah  
**Лицензия:** GNU GPL v3+

Программа живёт в системном лотке, следит за набором текста и исправляет слово,
если оно набрано в неправильной раскладке (QWERTY ↔ ЙЦУКЕН).

## Что нового в 0.985 beta

- Слово исправляется по пробелу, Enter или Tab — больше не рвётся на третьей букве (`clелай`, `jошибка`)
- Замена как в Punto Switcher: Backspace и повтор физических клавиш после смены раскладки, без буфера обмена и без веток под отдельные окна
- Слова с дефисом: `xnj-nj` → `что-то`
- Формы слов по основе: `htfkbpjdfyf` → `реализована`
- Горячие клавиши важнее автологики: Pause по пустому буферу конвертирует **выделение**
- Пробел не уходит в окно, пока слово не заменено (как в Punto Switcher)
- Раскладка меняется запросом в активное окно; раскладки системы не выгружаются
- Портативный режим: файл `portable` рядом с exe — настройки в каталоге программы, без автозагрузки

## Возможности

- Автопереключение EN ↔ RU по словарю после конца слова
- Эвристики невозможных сочетаний букв из xneur (`proto`)
- Словарь исключений: URL, IP, MAC, `.рф`, служебные слова; свои слова можно добавить
- Ручная конвертация текущего слова и выделенного текста
- Обучение: запомнить слово в словарь текущей раскладки
- Отмена последней конвертации (повторная отмена возвращает исправление)
- Горячие клавиши: клавиша из списка + Ctrl / Alt / Shift / Win
- Пропуск полей пароля и исключённых процессов
- Запуск вместе с Windows (не в портативной сборке)
- Окно параметров на русском
- Лёгкий нативный Win32-клиент без Qt/Electron

По умолчанию:

| Действие | Клавиши |
|---|---|
| Конвертировать слово | Pause |
| Конвертировать выделение | Ctrl+Pause |
| Добавить в словарь | Alt+Pause |
| Отменить конвертацию | Shift+Pause |

Pause без набранного слова тоже конвертирует выделение.

## Установка

Готовые файлы: [релизы на GitHub](https://github.com/TAPZAH/wxneur/releases).

- **Инсталлятор** `wxneur-0.985-beta-setup.exe` — в профиль пользователя, ярлык в меню Пуск
- **Портативная сборка** `wxneur-0.985-beta-portable.zip` — распаковать и запустить `wxneur.exe` (в архиве есть маркер `portable`)
- **Исходники** `wxneur-0.985-beta-src.zip` или репозиторий на GitHub

## Портативный режим

Рядом с `wxneur.exe` должен лежать файл с именем `portable` (без расширения). Тогда `config.json` пишется в ту же папку, автозагрузка через реестр отключена.

## Сборка

```
cmake -S . -B build -A x64
cmake --build build --config Release
```

Инсталлятор (NSIS):

```
makensis installer\wxneur.nsi
```
