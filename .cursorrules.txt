### 2. Файл `.cursorrules`
Создайте папку `.cursor` в корне проекта, а внутри неё файл `rules` (или `.cursorrules` в самом корне). Это заставит Cursor писать специфичный системный код правильно.

```text
# Cursor Rules for C++ Win32 Layout Switcher

You are an expert C++17/20 systems programmer specializing in Windows OS internals and Win32 API.

When writing code for this project, strictly follow these rules:

1. WIN32 API USAGE:
   - Always use the Unicode version of Win32 API functions (e.g., `CreateWindowExW`, `RegisterHotKey`, `Shell_NotifyIconW`).
   - Use `std::wstring` and `wchar_t` for all text processing.
   - Handle `HRESULT` and Win32 errors properly using `GetLastError()`.
   - Use RAII wrappers for Windows HANDLEs (e.g., `UniqueHandle` with custom deleter).

2. KEYBOARD HOOKING (WH_KEYBOARD_LL):
   - CRITICAL: The hook callback function MUST execute in < 300ms to prevent Windows from silently unhooking the app.
   - Do NOT perform heavy logic, dictionary lookups, or UI updates inside the hook callback.
   - The hook callback should only push the `KBDLLHOOKSTRUCT` data to a thread-safe queue or update an atomic buffer, then immediately call `CallNextHookEx`.
   - Run the message loop (`GetMessage`/`DispatchMessage`) in the main thread, and the hook setup in the same thread, OR use a dedicated background thread with its own hidden message pump.

3. INPUT SIMULATION:
   - Use `SendInput()` instead of the deprecated `keybd_event`.
   - When injecting text, use the `KEYEVENTF_UNICODE` flag.
   - Always send a `KEYEVENTF_KEYUP` immediately after `KEYEVENTF_KEYDOWN` for non-Unicode virtual keys.

4. MODERN C++:
   - Use C++17/20 features (`std::optional`, `std::variant`, `std::filesystem`, concepts if C++20).
   - Prefer `<thread>`, `<mutex>`, `<atomic>` over raw Windows threading APIs where appropriate.
   - Use `nlohmann/json` for configuration parsing.

5. MINIMALISM & PERFORMANCE:
   - Avoid heavy frameworks like Qt or wxWidgets. Use raw Win32 for UI elements (Tray, Menus) to keep the binary size under 500KB.
   - Memory footprint should be strictly monitored.
